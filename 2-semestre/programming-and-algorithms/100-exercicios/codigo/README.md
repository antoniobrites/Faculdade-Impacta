## Organização

- Os arquivos `.py` contêm os códigos-fonte dos exercícios.
- Os arquivos `.exe` são as versões compiladas para Windows 64 bits.
- Todos os arquivos seguem o padrão `exercicio-XXX` para manter a ordem numérica.
